HMWK 7 · Statistical independence: contingency tables and χ²

From a list of pairs (X, F) to a table of counts, then the expected counts under independence, the chi-square statistic and its p-value, and what the result does (and does not) say.

Do two things go together, or are they unrelated?

Take a group of people and write down two facts for each: X (say, the ticket class on the Titanic) and F (did the person survive?). If X tells you nothing about F, the two are independent. If knowing X changes what you expect for F, they are dependent (or "associated"). Here we count, compare with what independence would predict, and measure the gap with the χ² (chi-square) test.

🎲 Independence in probability

Events A and B are independent when P(A∩B) = P(A)·P(B). For two variables: P(X=i, F=j) = P(X=i)·P(F=j) for every pair (i, j). Same thing in words: P(F=j | X=i) = P(F=j), so the conditional frequencies in every row equal the marginal ones.

🧮 Independence in data

From the table of counts Oij (row totals ri, column totals cj, total n) independence predicts the expected counts Eij = ri·cj / n. The statistic is χ² = Σ (O−E)² / E: small if data look independent, large if not.

📉 The p-value

If X and F were really independent, χ² would still wobble by chance, following a χ² distribution with df = (rows−1)(columns−1). The p-value is the chance of getting a χ² at least as large as ours just by luck. A small p (below α) means "luck is not a good explanation".

✅ Result and verdict

🧠 Association is not causality

🔗 What the test can say

Only that the two variables are statistically associated: knowing one changes the odds of the other. A tiny p-value says the link is unlikely to be luck. It does not say how strong the link is (look at Cramér's V) nor why it exists.

🧩 What it cannot say

X may cause F, F may cause X, or a hidden third variable (a confounder) may drive both. A non-significant result is not proof of independence either: with few data the test simply has little power.

📏 Big n, tiny effects

With thousands of observations even a negligible difference becomes "significant". Always read p together with the effect size V (0 = nothing, 1 = perfect link). Try the simulator with n = 5000 and a very small s.

💻 How it is computed

// 1. contingency table from raw pairs (x_k, f_k)
O[x_k][f_k] += 1                    for k = 1..n
// 2. marginals and conditional frequencies
r_i = Σ_j O_ij ;  c_j = Σ_i O_ij ;  n = Σ r_i
P(F=j | X=i) = O_ij / r_i ;  P(X=i | F=j) = O_ij / c_j
// 3. expected counts if independent
E_ij = r_i · c_j / n
// 4. statistic and p-value
χ² = Σ (O_ij − E_ij)² / E_ij ;  df = (R−1)(C−1)
p  = Q(df/2, χ²/2)                  // upper incomplete gamma
V  = sqrt( χ² / (n · min(R−1, C−1)) )
