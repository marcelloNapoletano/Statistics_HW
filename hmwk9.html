HMWK 9 · Correlation and regression

What correlation measures, how the two regression lines are found, why r is the geometric mean of their slopes, and why independence implies uncorrelation (but not the other way round).

Do two variables move together?

For each unit we measure two numbers, X and Y (for example height and weight). Correlation says how well the points line up along a straight line; regression turns that line into a rule that predicts Y from X (or X from Y). The two ideas are two views of the same quantity.

📏 Covariance and correlation

Cov(X,Y) = E[(X − μX)(Y − μY)] is positive when large X goes with large Y. Dividing by both spreads gives the unit-free correlation r = Cov(X,Y) / (σXσY), always between −1 and +1 (Cauchy–Schwarz). r = ±1: points exactly on a line. r = 0: no linear relation.

📈 Two regression lines

"Y on X": the line y = a + bx minimising the squared vertical errors. "X on Y": the line x = a′ + b′y minimising the squared horizontal errors. They are different lines, crossing at the point of means (x̄, ȳ), unless all points lie exactly on a line.

🔗 The link: r² = b · b′

The slopes are b = r·sY/sX and b′ = r·sX/sY. Multiply them: the spreads cancel and b·b′ = r². So r is the geometric mean of the two regression coefficients, r = ±√(b·b′), with the sign that b and b′ share.

✏️ Solving the regression problem: finding a and b

We look for the line y = a + bx that makes the total squared vertical error as small as possible:

S(a, b) = Σ (yi − a − b xi)²

S is a bowl-shaped function of (a, b): its minimum is where both partial derivatives vanish.

∂S/∂a = 0

−2 Σ (yi − a − b xi) = 0 ⇒ ȳ − a − b x̄ = 0, so a = ȳ − b x̄: the line passes through (x̄, ȳ).

∂S/∂b = 0

−2 Σ xi(yi − a − b xi) = 0. Substituting a and using centred sums Sxy = Σ(x−x̄)(y−ȳ), Sxx = Σ(x−x̄)²: b = Sxy/Sxx = r · sY/sX.

It is a minimum

S(b) = Syy − 2b Sxy + b² Sxx is a parabola opening upwards (Sxx > 0). At the best slope S = Syy(1 − r²): the fraction r² of the variation of Y is "explained" by X.

The other line

Swap the roles: x = a′ + b′y with b′ = Sxy/Syy = r · sX/sY, a′ = x̄ − b′ȳ. Then b · b′ = Sxy² / (SxxSyy) = r², which is the verification asked for (checked numerically above for every dataset).

🧩 Proof: independence implies uncorrelation

Claim. If X and Y are independent and have finite variances (positive, so that r exists), then Cov(X,Y) = 0 and hence r = 0.

Step 1 · Rewrite the covariance

Cov(X,Y) = E[(X − μX)(Y − μY)] = E[XY] − μXμY (expand the product, use linearity of E). So we only need E[XY] = E[X]E[Y].

Step 2 · Use independence (discrete case)

Independence means P(X=x, Y=y) = P(X=x)P(Y=y). Then E[XY] = ΣxΣy xy P(X=x)P(Y=y) = (Σx x P(X=x)) (Σy y P(Y=y)) = E[X]E[Y].

Step 2′ · Continuous case

The joint density factorises, f(x,y) = fX(x)fY(y), so E[XY] = ∬ xy fX(x)fY(y) dx dy = (∫ x fX dx)(∫ y fY dy) = E[X]E[Y] (Fubini's theorem; the integrals converge absolutely because E|X|, E|Y| < ∞ and, by independence, E|XY| = E|X|E|Y| < ∞).

Step 3 · Conclude

Cov(X,Y) = E[X]E[Y] − μXμY = 0, so r = Cov/(σXσY) = 0. Equivalently, both regression slopes b = r sY/sX and b′ are 0: knowing X does not move the best linear prediction of Y. ∎

The converse is false. Let X be symmetric about 0 (for instance uniform on {−1, 0, 1}) and Y = X². Then Y is a function of X, so they are as dependent as can be, yet E[XY] = E[X³] = 0 = E[X]E[Y], so Cov(X,Y) = 0. Correlation only detects linear dependence. (Only for jointly normal variables does r = 0 imply independence.) Try the last two views to see it in simulations.

Why the hypothesis on variances? For the Cauchy distribution E|X| = ∞, so neither E[XY] nor r is defined even though X and Y may be independent.

💻 How it is computed

mx = mean(x); my = mean(y)
Sxx = Σ (x − mx)²;  Syy = Σ (y − my)²;  Sxy = Σ (x − mx)(y − my)
b  = Sxy / Sxx;   a  = my − b  · mx        // Y on X
b2 = Sxy / Syy;   a2 = mx − b2 · my        // X on Y
r  = Sxy / sqrt(Sxx · Syy)
check:  b · b2 = r²   ⇒   r = sign(Sxy) · sqrt(b · b2)
